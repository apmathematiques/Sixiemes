# GeoLib 1.4.1 — Compas V4

Cette V4 corrige :
- la tête remise à l'endroit ;
- des branches plus fines ;
- des branches plus longues ;
- une silhouette plus proche du visuel de référence ;
- la continuité de la manipulation tactile grâce à la capture du pointeur.

## Test

Copier `geolib/v1.4.1/` dans le dépôt puis lancer :

`py -m http.server 8000`

Ouvrir :

`http://localhost:8000/geolib/v1.4.1/demo-compass.html`
